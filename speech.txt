Good morning everyone, and esteemed panel members from Bharat Electronics Limited. Today, I am thrilled to present our solution for the Smart Automation theme, specifically addressing Problem Statement ID26123: "Edge-AI Based Distributed Fleet Coordination for Autonomous Mobile Robots in Smart Warehouses."

Imagine a massive, bustling modern smart warehouse. Goods need to be moved seamlessly, efficiently, and continuously. To achieve this, we deploy fleets of Autonomous Mobile Robots, or AMRs. Traditionally, these robots rely heavily on a centralized cloud server. The server acts like a traffic controller, telling every robot exactly where to go and when. However, as fleets grow larger and operations become more complex, this centralized architecture starts to crack under pressure. High network latency can delay critical commands. Wi-Fi dead-zones in dense storage aisles can leave robots stranded, and ultimately, the central server represents a catastrophic single-point-of-failure. If the server goes down, the entire warehouse grinds to a halt.

To build a robust, future-proof warehouse, we need a paradigm shift. We must move away from top-down centralization and embrace decentralized, edge-computing solutions. Our robots need the ability to talk directly to each other and make split-second, intelligent decisions on the fly, entirely locally. 

This brings us to the core objective of our project: We have designed and built a comprehensive decentralized coordination and collision-avoidance framework for a multi-robot fleet operating in a highly dynamic environment. 

Our application is a full-stack simulation platform that proves the viability of this decentralized edge-AI approach. We built the backend simulation engine in Python, representing the localized edge-hardware logic that would run on devices like a Raspberry Pi or a Jetson Nano directly onboard each AMR. The frontend, built with React and Vite, provides a seamless, lightweight monitoring dashboard. 

Let me walk you through the key functionalities of our application and how we have meticulously addressed every requirement of the problem statement.

First and foremost is Decentralized Communication. In our application, we have completely eliminated the central path-planning server. Instead, we implemented a peer-to-peer Message Bus protocol. In the codebase, each robot is instantiated as an independent software agent. These agents communicate over the simulated decentralized network stack to broadcast their current positions, their intended paths, and their operational status. Because this communication happens locally—robot to robot—it is immune to widespread Wi-Fi dead zones and server outages. If two robots approach the same aisle, they negotiate their movements directly with each other.

This leads us to our second major feature: Dynamic Multi-Agent Conflict Resolution. What happens when two robots want to cross the same narrow intersection at the same time? In a traditional system, one might simply stop and wait indefinitely, or worse, they might collide. We tackled this by implementing advanced temporal planning and deadlock detection algorithms directly on the edge nodes. Our robots use a space-time A-star algorithm. They don't just plan a path through physical space; they plan through time. When a robot receives intent data from a peer via the decentralized network, it dynamically updates its own spatial-temporal map. If our Deadlock Detector identifies a potential choke point, the built-in Conflict Resolver steps in. The robots negotiate priority based on task urgency and reroute themselves in real-time. The result? Smooth, continuous movement through tight spaces without the need for a central traffic cop.

But what if a path is completely blocked? Say, a pallet has fallen in an aisle. This brings us to the third core functionality: Task Allocation and Re-routing. Our decentralized Task Manager ensures that the fleet remains productive even in the face of unexpected obstacles. If a robot encounters a blockage that it cannot bypass locally, it immediately flags the path as impassable on the shared local network. If it is carrying a critical payload, it calculates an alternative route on the fly. If its current task becomes impossible, the decentralized task allocator can reassign the pickup point to another robot that has a clearer path. This dynamic re-routing ensures that single aisle blockages never cascade into warehouse-wide delays.

While the fleet operates autonomously, human oversight is still necessary. Therefore, we developed a sleek, lightweight Fleet Dashboard. Built with React, this UI connects to the robot network purely as an observer. It provides warehouse managers with a bird's-eye view of the entire fleet. The dashboard visualizes real-time positions on the warehouse grid, maps out intended paths, monitors battery statuses, and displays active tasks. It is designed to be highly responsive, providing critical operational intelligence without interfering with the decentralized decision-making loop of the AMRs. 

Finally, let's talk about the results and our success criteria. We didn't just build a theoretical model; we rigorously tested it using an automated benchmarking suite built into the application. We ran hundreds of simulations featuring multiple overlapping paths, choke points, and dynamic obstacles. 

I am proud to report that our Edge-AI decentralized framework achieved zero inter-robot collisions across all test scenarios. Furthermore, we compared our spatial-temporal conflict resolution against traditional stop-and-wait methods. Our benchmarking results demonstrate a significant performance leap, comfortably exceeding the required 20% reduction in total task completion time. By enabling robots to negotiate and flow around each other rather than simply stopping, the overall throughput of the warehouse is drastically improved.

In conclusion, what we have built is more than just a simulation; it is a blueprint for the next generation of smart automation. By pushing intelligence to the edge and empowering robots to coordinate directly, we have created a system that is faster, more resilient, and infinitely more scalable than legacy centralized architectures. This framework ensures continuous operation, maximizes efficiency, and completely eliminates the risks associated with single points of failure. 

We believe this decentralized approach represents the future of autonomous mobile robotics for Bharat Electronics Limited and the wider industry. Thank you for your time, and I would be happy to answer any questions you might have about our implementation, the algorithms used, or the architecture of the platform.
